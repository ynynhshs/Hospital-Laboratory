# MediLink - Laboratory Request and Results Management System

## Project Overview
A standalone laboratory subsystem developed as part of the MediLink Integrated Hospital Management System.

## Technology Stack
- Frontend: HTML, CSS, and JavaScript
- Backend: Node.js and Express.js
- Database: MongoDB Atlas with Mongoose

## Development Status
Project initialization.

## Important Note
This subsystem is being developed and tested independently before any future integration with the other MediLink subsystems.
